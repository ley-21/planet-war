# 🪐 행성 점령전

오라룩스(Auralux) 스타일의 실시간 전략 게임입니다. 반 친구들끼리 **6자리 방 코드**로 모여서 해요.

## 게임 방법
1. 닉네임 + **숫자 6자리 방 코드** 입력 → 입장 (없는 코드면 새 방)
2. **전원 준비완료** → 3초 후 시작 (1~30명)
3. 내 행성에서 유닛이 계속 생겨요. 유닛을 골라서 다른 행성으로 보내세요.
4. 상대의 행성과 유닛을 모두 없애면 승리! (10분이 지나면 남은 세력 점수로 순위)

### 조작
| 동작 | 방법 |
|---|---|
| 유닛 선택 | 마우스/손가락으로 **드래그해서 동그라미 그리기** → 안에 있는 내 유닛 선택 (Shift 누르면 추가 선택) |
| 행성 유닛 전부 선택 | 내 행성 클릭 |
| 보내기 | 유닛 선택 후 **목적지 행성 클릭** |
| 선택 취소 | 빈 곳 클릭 / Esc |
| 확대·축소 | 마우스 휠 / 두 손가락 벌리기 |
| 화면 이동 | 우클릭 드래그 / 두 손가락 드래그 / "전체 보기" 버튼 |

### 규칙
- **생산:** 레벨 1 행성은 1초에 유닛 1개 (레벨 2는 2개, 레벨 3은 3개)
- **중립 행성 점령:** 유닛을 넣어서 점령 (작은 행성 10개, 중간 15개, 큰 행성 20개 필요). 다른 사람이 점령하던 중이면 그 진행도부터 깎아야 해요.
- **업그레이드:** 내 행성에 내 유닛을 보내면 레벨이 올라요 (1→2: 20개, 2→3: 30개). 행성 크기(고리 개수)만큼 최대 레벨이 정해져 있어요. 다 업그레이드된 행성에 보낸 유닛은 그대로 주둔해요.
- **전투:** 적 행성에 보내면 주둔 유닛과 1:1로 상쇄되고, 남은 유닛이 행성 내구도를 깎아요. 내구도가 0이 되면 중립 행성이 돼요. 날아가다가 적 유닛 무리와 만나도 1:1로 상쇄돼요.
- **화면 읽는 법:** 행성 가운데 숫자는 주둔 유닛 수예요. 중립 행성은 "점령 진행도/필요 개수"로 표시돼요. 행성 바깥 고리는 점령·내구도·업그레이드 진행도예요.

### 인원별 맵
- **1명:** 일직선 행성 5개, 양 끝에 나와 🤖 AI
- **2명:** 같은 일직선 맵에서 1:1
- **3명 이상:** 중앙에 큰 행성, N각형 꼭짓점마다 각자의 본진, 나머지 행성은 랜덤 배치

## 실행 / 배포
지렁이 게임과 똑같아요.
```bash
npm install
npm start      # http://localhost:3000
```
Render 배포도 같은 방법이에요 (Build `npm install`, Start `npm start`, Free, Region Singapore).
지렁이 게임과 **별도의 GitHub 저장소 + 별도의 Render 서비스**로 만들면 돼요.

## 설정 바꾸기 (`server.js` 맨 위)
| 값 | 기본 | 설명 |
|---|---|---|
| `ROUND_SECONDS` | 600 | 제한 시간(초) |
| `FLEET_SPEED` | 90 | 유닛 이동 속도 |
| `START_UNITS` | 5 | 시작 유닛 |
| `AI_THINK_SECONDS` | 1.2 | AI 판단 간격 (클수록 쉬워짐) |
| `capCost` | 10/15/20 | 중립 점령 비용 |
| `upCost` | 20/30 | 업그레이드 비용 |
